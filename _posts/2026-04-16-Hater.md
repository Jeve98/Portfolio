## 기획 배경 및 의도

### 기획 배경

디펜스 장르는 과거의 '공격 받지 않는 기물을 설치하는 타워 디펜스'부터 현재의 '수집형 RPG와 결합된 실시간 조작 디펜스'까지, 기본 시스템에 대한 다양한 해석과 타 장르와의 결합을 바탕으로 **높은 확장성을 가진 스테디셀러 장르**라고 할 수 있다.

하지만 대다수의 디펜스 장르에서 고수하고 있는 하나의 시스템이 존재한다. 바로 **현재 스테이지에서의 행동이 다음 스테이지에는 영향을 끼치지 못한다**는 것이다. 예컨대, 한 스테이지의 자원 소모량은 스테이지 클리어 시의 결과 등급에 영향을 줄 뿐, 다음 스테이지에는 아무런 영향을 끼치지 않는다. 수집형 RPG와 결합된 디펜스 게임의 경우에도 한 스테이지에서 쓰러진 캐릭터는 아무런 문제 없이 다음 스테이지에서 사용이 가능하다.

디펜스 장르의 본질은 전쟁 중에 나의 기지를 지키는 것에 있다. 현실이라면 한 번의 전투는 이후의 전투에 직접적인 영향을 준다. 이러한 현실의 제약사항을 적절히 게임에 녹여낸다면, 게임의 몰입감을 높일 수 있을 것이다.

이에 **미래의 플레이를 고려하며 현재를 플레이**하는 디펜스 게임을 기획하고자 한다. 즉, 미래를 위해 기물을 아낄 경우 클리어가 어려워지고, 안전한 승리를 위해 기물을 무분별하게 사용할 경우 이후의 플레이 난이도가 증가하도록 설계하여 끊임없이 고민해야하는 결정권자로써의 경험을 만들 수 있다. 다만 이를 위해서는 각 스테이지에서 Wave를 랜덤하게 구성하여 **동일한 전략으로 스테이지를 클리어할 수 없도록** 하는 것을 전제로 한다. 만약 모든 스테이지가 사전에 결정되어있다면 기물을 아끼거나 낭비하는 선택지 자체가 성립하지 않기 때문이다.

디펜스 장르에는 또 하나 한계점이 존재한다. 바로 다회차 플레이가 성립하지 않는다는 것이다. 스테이지 정보와 적 유닛 특성을 이미 알고 있는 유저에게 다회차 플레이는 그저 반복 요소에 불과하기 때문이다. 이는 앞선 랜덤 Wave 구성 뿐만 아니라, 스테이지 종료 시에 조우한 적 유닛의 특성을 도감 형식으로 제공하는 것으로 해소할 수 있을 것이다.

### 기획 의도

기획 배경을 바탕으로 다음 설계 결정을 내렸다.

| 결정                                 | 근거                                                                                                                                                                  | 구현 방향                                                                                 |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 병력의 영구적 손실                   | 스테이지 결과를 이후 전투에 이어지게 함으로써 미래를 고려하는 플레이가 성립                                                                                           | 전투 사망 병력은 가용 인원에서 영구적으로 제거                                            |
| 배타적인 선택지, 탐사 vs 사령관 모집 | 기회비용(사령관)을 소모하여 미래와 현재의 안전성 중에서 하나를 선택하도록 강제함으로써 미래와 현재에 대한 선택 요소로 작용                                            | 스테이지 성공 후 둘 중 하나만 선택 가능                                                   |
| 랜덤 Wave 구성                       | 동일한 전략의 반복 방지                                                                                                                                               | 스테이지 단계별 난이도는 일정해야하므로 난이도 별 Wave 조합                               |
| 적 유닛 정보 은닉                    | 점차 공개되는 정보를 기반으로 다회차에 대한 정보 우위적 동기 발생                                                                                                     | 스테이지 종료 시에 조우한 적 유닛에 대한 도감 공개. 공개된 도감 정보는 이후에도 확인 가능 |
| 탐사의 정신력 소모 구조              | 기회비용만을 비용으로써 처리할 경우, 충분한 수의 사령관을 획득한 후반부에서 탐사 컨텐츠의 리스크가 0에 수렴하므로 추가적인 비용 소모가 필요                           | 탐사 진행 시 사령관 정신력 소모, 절반 미만 시 다음 스테이지에서 사용 불가                 |
| 골드 소모를 통한 추가 배치           | 전쟁 단계에서 추가적인 배치를 금지할 경우, 해당 단계는 수동적인 관람에서 머무름. 또한 골드라는 자원이 있음에도 추가적인 배치가 불가능하기 때문에 패배하는 경우가 발생 | 전쟁 단계에서 골드 소모로 추가 병력 배치 가능, 해당 병력은 게임 종료 후 편입              |

## 게임 필라 및 코어 루프

### 게임 필라

| 필라              | 설명                                                                  | 구현 방법                                                  |
| ----------------- | --------------------------------------------------------------------- | ---------------------------------------------------------- |
| 지속성 전쟁       | 현재의 손실이 미래를 결정한다                                         | 스테이지 간 병력, 골드, 사령관 등 자원 공유                |
| 전략적 딜레마     | 아끼면 지고, 쓰면 미래의 난이도가 높아진다                            | 골드 소모 추가 배치, 탐사 비용 구조                        |
| 정보 비대칭       | 정보를 알면 유리하지만 그 비용은 비싸다                               | 탐사로 Wave 정보 획득 시 사령관 정신력 소모, 기회비용 발생 |
| 적 유닛 정보 은닉 | 점차 개방되는 정보를 기반으로 다회차 플레이 시의 정보 우위를 생성한다 | 스테이지 종료 시에 조우한 적 유닛에 대한 정보 개방         |
| 반복 가능성       | 매 회차 다른 전장을 경험한다                                          | 난이도별 랜덤 Wave 조합, 다양한 사령관                     |

## 컨텐츠 구조

### 디펜스

| 단계      | 설명                                    | 제약                                                                               |
| --------- | --------------------------------------- | ---------------------------------------------------------------------------------- |
| 배치 단계 | Cell에 병력 배치, 사령관 위치 결정      | Wave 정보 비공개. 배치 취소 가능                                                   |
| 전쟁 단계 | 배치된 병력과 적 유닛의 시뮬레이션 전투 | 재배치 불가. 골드 소모로 추가 배치 가능 (추가 배치된 병력은 이후 보유 병력에 편입) |

**스테이지 클리어 실패 조건**

- 성벽 체력이 0이 된 경우
- 배치 병력 전멸 + 추가 배치 가능한 골드 없음

### 탐사

| 항목             | 내용                                                                                    |
| ---------------- | --------------------------------------------------------------------------------------- |
| 진입 비용        | 사령관 선택                                                                             |
| 스테이지 수      | 5개                                                                                     |
| 매 스테이지 효과 | 사령관 정신력 랜덤 감소                                                                 |
| 보상             | 스테이지마다 다음 Wave 정보 획득                                                        |
| 최종 보상        | 마지막 스테이지 도달 + 정신력 잔존 시 강력한 사령관 획득                                |
| 제약             | 정신력 50% 미만 사령관은 다음 방어전에서 사용 불가능                                    |
| 선택지           | 매 스테이지마다 진입 / 종료 선택 가능. 단, 모든 사령관의 정신력이 0이 될 경우 자동 종료 |

## 시스템 명세 (예시)

### 사령관

디펜스에서는 특정 Cell에 배치되어 인근 병력에게 패시브 버프를 제공한다.  
탐사에서는 소모 자원으로 사용된다.

| 종류                  | 효과                              |
| --------------------- | --------------------------------- |
| 물리 데미지 향상      | 인근 병력의 물리 공격력 증가      |
| 마법 데미지 향상      | 인근 병력의 마법 공격력 증가      |
| 고정 마법 데미지 추가 | 모든 공격에 고정 마법 데미지 추가 |
| 방어력 향상           | 인근 병력의 방어력 증가           |
| 회복량 향상           | 인근 병력의 회복 효과 증가        |

### 아군 병력

5개 병과로 구성된다. 병력 수는 HP와 동일하게 취급되어 전투 피해에 따라 감소한다.  
일정 횟수의 전투를 경험하면 등급이 상향되며, 하위 부대 편입으로 인원을 보충할 수 있다.

| 병과   | 특성                                                 |
| ------ | ---------------------------------------------------- |
| 보병   | 평균적인 방어력과 물리 공격력                        |
| 마법병 | 낮은 방어력, 높은 마법 공격력                        |
| 포병   | 높은 방어력과 물리 공격력. 범위 공격, 느린 공격 속도 |
| 방패병 | 높은 방어력, 낮은 물리 공격력                        |
| 신관   | 낮은 방어력. 주위 병력 회복                          |

### 적 유닛

단일 병과만으로 모든 적을 처리하는 전략을 방지하기 위해 다양한 특성을 부여한다.

| 특성        | 효과                                                      |
| ----------- | --------------------------------------------------------- |
| 물리 면역   | 물리 공격 피해 무효                                       |
| 마법 면역   | 마법 공격 피해 무효                                       |
| 범위 면역   | 범위 공격 피해 무효                                       |
| 회복 불가   | 아군 유닛의 회복 효과 차단                                |
| 데미지 반사 | 입은 피해만큼 공격자에게 반사. 대신 체력이 매우 낮음      |
| 원거리 공격 | 근접 배치 병력을 넘어 후열 공격 가능                      |
| 돌파        | 병력 유닛을 무시하고 성벽 직접 공격                       |
| 그로기      | 매우 높은 체력. 누적 피해 일정량 초과 시 그로기 상태 진입 |
