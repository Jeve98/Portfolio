> 한 판은 20~30분, 하지만 선택의 흔적은 다음 캐릭터까지 남는다."**

## 2. 기획 배경

### 왜 캐릭터 애착인가

게임 몰입을 결정하는 가장 강력한 요소는 **캐릭터에 대한 애정**이다.  
금전 투자보다 캐릭터의 서사와 매력이 플레이어를 붙잡는다.

그러나 현재 모바일 시장은 실시간 조작 중심 게임이 주류를 이루고 있어, **연령대가 올라갈수록 접근이 어렵다.**  
펌블은 턴제 시스템을 채택하여 조작 부담을 낮추고, 판당 20~30분이라는 플레이 시간으로 바쁜 플레이어를 배려한다.

## 4. 핵심 게임플레이 루프

```
[캐릭터 생성 — 다이스 롤로 스탯 분배]
        ↓
[여정 선택 — 지역별 등급 구성]
        ↓
[이벤트 발생 — 전투/미스테리/조우/사고 등 11종]
        ↓
[다이스 롤로 결과 결정]
        ↓
[선택에 따라 플래그 기록 → 이후 여정에 반영]
        ↓
[캐릭터 사망 시 — 유산 이벤트로 다음 캐릭터에 일부 계승]
        ↓
[새 캐릭터로 반복 — 세계는 이전 선택의 흔적이 남아있음]
```

## 5. 핵심 차별점 — 세 가지

### 차별점 1: 세계가 변한다 (플래그 기반 세계 변화)

플레이어의 선택이 즉시 보이는 결과로 나타나지 않는다.  
이전 여정의 선택이 이후 여정에서 조용히 반영된다.

```
// 설계 예시
flag: eventSeol = true
flag: saveSeol = true

if !eventSeol:
    "동생이 산적에게 납치되었어요..."  // 첫 만남
else:
    if saveSeol:
        "과거에 모험가님과 닮은 분이..."  // 구출했을 때
    else:
        (등장하지 않음)  // 구출 안 했을 때
```

플레이어는 "내가 예전에 한 선택이 여기서 영향을 미쳤구나"를 나중에야 발견한다.

---

### 차별점 2: 캐릭터가 죽어도 서사가 이어진다 (유산 시스템)

캐릭터 사망 시 단순히 처음부터 시작하는 것이 아니라, 유산 이벤트를 통해 3가지 선택지 중 하나를 고른다.  
이전 캐릭터의 아이템, 스탯, 관계가 일부 다음 캐릭터에 전해진다.

플레이어가 캐릭터의 죽음을 "실패"가 아닌 "이야기의 한 챕터"로 느끼도록 설계했다.

---

### 차별점 3: 펌블과 스페셜 — 주사위가 서사가 된다

TRPG에서 d20을 굴려 1이 나오는 순간(펌블)은 상황을 극적으로 망친다.  
최댓값이 나오는 순간(스페셜)은 모든 것이 완벽하게 맞아떨어진다.

이 게임은 그 극적인 순간을 시스템의 중심에 놓는다.  
프로젝트 이름 "펌블"은 이 메커닉에서 왔다.

## 6. 시스템 설계 요약

### 6-1. 기본 스탯 및 다이스 시스템

| 스탯 | 연관 다이스 | 효과 |
|------|------------|------|
| 힘 | d10, d12 | 체력, 물리 공격 |
| 민첩 | d8, d10 | 공격 순서, 회피 |
| 지능 | d8, d12 | 미스테리 판정, 마법 |
| 행운 | d20 | 행운 판정, 다이스 재시도 확률 |

다이스 종류: d4 · d6 · d8 · d10 · d12 · d20

---

### 6-2. 특수 스탯 7종 (7대 죄악 모티프)

| 스탯 | 효과 요약 |
|------|---------|
| 분노 | 적대 NPC 처치 시 영구 제거 + 보상 상향 |
| 탐욕 | 아이템/재료 획득 롤에 보정 |
| 오만 | 펌블 시 재시도, 스페셜 시 펌블 대체 |
| 나태 | 스페셜 시 3배 효과, 기본 패널티 증가 |
| 색욕 | 우호 NPC와의 거래 어드밴티지 |
| 질투 | 모든 롤에 d20 추가 |
| 식욕 | 모든 비소모품 섭취 가능 + 스탯 소폭 상승 |

---

### 6-3. 여정 이벤트 11종

| 이벤트 | 핵심 내용 |
|--------|---------|
| 전투 | 몬스터 처치 + 드랍 롤 |
| 미스테리 | 서브 여정, 절세 이상 실패 시 사망 위험 |
| 명소 | 풍경 일러스트 획득, 다음 이벤트 소폭 보너스 |
| 수집 | 지역 재료 획득 롤 |
| 조우 | NPC 만남, 관계에 따라 결과 분기 |
| 사고 | 천재지변, 영구 손상 또는 보너스 |
| 야영 | 취침/강행군 선택 |
| 회상 | 야영 취침 시 발생, 스탯 랜덤 상승 |
| 흔적 | 숨겨진 여정/아이템 발견 |
| 신기루 | 희귀 아이템 또는 영구 손상 |
| 유산 | 전 캐릭터 사망 여정 재현 + 3가지 계승 선택 |

---

## 7. 경쟁작 분석 및 차별점

| 게임 | 공통점 | 차별점 |
|------|--------|--------|
| Hades | 죽음 후 서사 지속, 반복 플레이 | Hades는 액션 중심, 펌블은 턴제/다이스 중심 |
| 80 Days | 선택 기반 여정, 세계 변화 | 80 Days는 텍스트 어드벤처, 펌블은 RPG 시스템 결합 |
| D&D 기반 게임들 | TRPG 메커닉 | 펌블은 모바일 최적화 + 멀티플레이 통합 |

**펌블의 핵심 차별점:**  
"캐릭터가 죽어도 세계가 기억한다" — 로그라이크의 반복성과 서사 RPG의 캐릭터 애착을 결합하는 지점이 기존 경쟁작에 없는 포인트다.
