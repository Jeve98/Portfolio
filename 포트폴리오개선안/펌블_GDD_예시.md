| 한줄 설명 | 세대를 이어가며 성장하는 나만의 캐릭터로 다이스 롤 기반 여정을 떠나는 턴제 RPG |

## 기획 의도

RPG 리텐션의 핵심은 캐릭터 애정도다. 자본보다 강력하고 지속적인 이 요소는 유저가 캐릭터를 '또 다른 자신'으로 인식할 때 발생한다. 그러나 현대 RPG 주 이용층은 연령대가 높아지며 고난도 조작보다 전략 중심의 짧은 판을 선호하는 방향으로 이동하고 있다.

이에 다음 세 가지를 동시에 달성하는 게임을 목표로 기획하였다.

1. **긴 호흡의 육성** — 수많은 선택지를 통해 캐릭터에 대한 감정적 투자를 유도한다.
2. **짧은 판 구조** — 여정 하나는 20~30분으로 완결되어 진입 장벽을 낮춘다.
3. **세대 계승 서사** — 캐릭터의 영구 사망을 '끝'이 아닌 '다음 세대로의 계승'으로 전환하여 이탈을 방지한다.

## 게임 필라 (Game Pillars)

| 필라 | 설명 | 구현 방법 |
|------|------|-----------|
| 캐릭터 애정도 | 캐릭터가 나의 분신이 되도록 설계 | 긴 호흡 육성, 다이스 롤 기반 캐릭터 생성, 100여 종 일러스트 |
| 선택의 연속성 | 내 선택이 세계를 변화시킨다는 체감 | NPC 플래그 시스템, 이전 회차 선택의 현 회차 반영 |
| 단판 완결 | 20~30분 여정으로 부담 없는 플레이 | 여정 단위 컨텐츠, 빠른 여정 기능 |
| 세대 계승 | 사망이 끝이 아닌 서사의 연속 | 유산 이벤트 (스탯/아이템/특수 스탯 계승) |

## 코어 루프 (Core Loop)

```
[캐릭터 생성]
    다이스 롤 → 기본 스탯(힘/민첩/지능/행운) 분배
        ↓
[여정 선택]
    대륙 지도에서 여정 선택 (초행 → 상설 → 주의 → 위험 → 절세 → 인외 순 해금)
        ↓
[이벤트 연쇄]
    전투 / 미스테리 / 명소 / 수집 / 조우 / 사고 / 야영 / 흔적 / 신기루
        ↓
[결과 적용]
    ├─ 성공: 경험치 · 아이템 획득 → 성장 → 다음 여정
    └─ 사망: 유산 이벤트 발동 → 새 캐릭터로 계승 → 반복
```

**단판 루프 (여정 내부)**

```
여정 진입 → 이벤트 N회 연쇄 → 여정 성공/실패 판정 → 보상 획득 → 대륙 지도 복귀
```

## 컨텐츠 구조

### 현실 (솔로)
캐릭터를 생성하고 여정으로 성장시키는 메인 컨텐츠. 여정에서 사망한 캐릭터는 영구 삭제된다.

| 컨텐츠 | 설명 | 비고 |
|--------|------|------|
| 여정 | 1챕터 = 복수의 이벤트. 성공/실패에 따라 성장폭 차이 | 20~30분 목표 |
| 빠른 여정 | 이미 경험한 여정을 즉시 완료 | 미스테리·명소·조우 이벤트 미발생 |

### 환영 (2인)
생성한 캐릭터로 다른 플레이어와 대전 또는 거래하는 컨텐츠. 대전 결과로 인한 손상은 영구 적용된다.

| 컨텐츠 | 설명 |
|--------|------|
| 대전 (친선) | 패널티 없는 결투 |
| 대전 (적대) | 패배 캐릭터에 영구 손상, 승리 시 명성 획득 |
| 대전 (내기) | 아이템 또는 명성을 걸고 진행. 패배 시 영구 손상 |
| 거래 | 다이스 롤로 거래 아이템 품질 변동. 해당 지역 드랍 아이템만 거래 가능 |
| 명성 | 대전으로 획득. 상위 랭커에게 특수 아이템/스탯 대여 |

### 여행 (다인)
현실 컨텐츠에서 설치한 거점으로 이동, 다른 플레이어와 대화하는 소셜 컨텐츠.

## 시스템 명세

### 다이스 시스템

| 다이스 | 범위 | 주요 사용처 |
|--------|------|------------|
| d4 | 1~4 | 낮은 리스크 판정 |
| d6 | 1~6 | 기본 전투/수집 |
| d8 | 1~8 | 중간 난이도 판정 |
| d10 | 1~10 | 높은 리스크 판정 |
| d12 | 1~12 | 고난이도 여정 |
| d20 | 1~20 | 특수 스탯 질투 발동 시 추가 롤 |

- **펌블**: 다이스 결과값 1 → 판정에 큰 악영향
- **스페셜**: 다이스 최댓값 → 판정에 큰 선영향

### 캐릭터 스탯

**기본 스탯** (생성 시 다이스 롤 후 자유 분배)

| 스탯 | 주요 영향 | 임계치 보상 |
|------|-----------|------------|
| 힘 | 체력, 공격 보정 | 특별 스킬 해금 |
| 민첩 | 공격 순서, 회피 보정 | 특별 스킬 해금 |
| 지능 | 미스테리 이벤트, 마법 보정 | 특별 스킬 해금 |
| 행운 | 다이스 롤 전반 보정 | 재시도 확률 추가 (수치 단계마다) |

**특수 스탯** (이벤트·아이템으로 획득. 설명은 인게임에서 비공개)

| 스탯 | 효과 |
|------|------|
| 분노 | 적대 NPC 환영 승리 시 영구 제거 + 보상 획득. 수치↑ → 보상 수준↑ |
| 탐욕 | 아이템·재료 획득 다이스 롤에 보정치. 수치↑ → 보정치↑ |
| 오만 | 펌블 발생 시 다이스 롤 → 스페셜 나오면 펌블을 스페셜로 대체. 수치↑ → 더 강한 다이스 사용 (d12→d4 순) |
| 나태 | 스페셜 영향 3배, 단 스페셜 값에 패널티% 적용. 수치↑ → 패널티↑ (75 이상) |
| 색욕 | 우호 NPC와의 거래에서 어드벤티지. 수치↑ → 어드벤티지↑ |
| 질투 | 다이스 롤 시 d20 추가 롤. 결과값 × 수치 / 10 가산 |
| 식욕 | 비소모품 섭취 가능. 낮은 확률로 기본 스탯 소폭 상승. 수치↑ → 확률↑ |

### 여정 이벤트 명세

| 이벤트 | 설명 | 특이사항 |
|--------|------|----------|
| 전투 | 몬스터 전투. 승리 후 다이스 롤로 추가 아이템 획득 | — |
| 미스테리 | 서브 여정 발생. 절세 이상 등급 실패 시 캐릭터 사망 | — |
| 명소 | 풍경 일러스트(월페이퍼) 획득. 다음 이벤트에 미미한 선영향 | 거점 설치 가능 |
| 수집 | 다이스 롤로 해당 지역 재료 획득 | — |
| 조우 | NPC 조우. 관계(우호/적대)에 따라 이후 여정에 영향 | 플래그 연동 |
| 사고 | 천재지변. 선/악영향 또는 영구 손상 | 전용 일러스트 처리 |
| 야영 | 취침(HP·MP 회복) 또는 강행군 선택 | 취침 시 전투·조우·사고·회상 확률 발생 |
| 회상 | 야영-취침 시만 발생. 미스테리 확률↑, 기본 스탯 랜덤 상승 | — |
| 흔적 | 숨겨진 여정·아이템·재료 획득. 일정 확률로 전투 이어짐 | — |
| 신기루 | 다이스 롤. 희귀 아이템/여정 획득 또는 영구 손상 | — |
| 유산 | 직전 회차 캐릭터 사망 여정에서 발생. 3가지 계승 중 선택 | 세대 계승 핵심 이벤트 |

**유산 이벤트 계승 선택지**

1. 직전 캐릭터의 최고 스탯 10% 해당 스탯에 추가
2. 직전 캐릭터 보유 아이템 중 최고 등급 1개 획득 (동급 복수 시 랜덤 선택)
3. 직전 캐릭터의 특수 스탯 1 획득 (특수 스탯 보유 시에만)

### 여정 등급

| 등급 | 특이사항 |
|------|----------|
| 초행 | 최초 1회 한정 여정 |
| 상설 | 반복 도전 가능 |
| 주의 | 중간 난이도 |
| 위험 | 사망 리스크 증가 |
| 절세 | 미스테리 실패 시 캐릭터 사망 |
| 인외 | 최고 난이도 |

**장비 등급**

| 등급 | 비고 |
|------|------|
| 초기 | 기본 지급 |
| 일반 | — |
| 수작 | — |
| 명작 | 인게임 아바타(말)에 외형 반영 |
| 절세 | 인게임 아바타(말)에 외형 반영 |

## 플래그 시스템 설계

유저의 선택이 세계에 영향을 미친다는 체감을 만들기 위해 플래그 시스템을 채택하였다.  
각 이벤트의 발생 여부와 선택 결과를 플래그로 저장하고, 이후 회차에서 동일 NPC 조우 시 해당 플래그를 참조하여 다른 대사와 관계를 제공한다.

**설계 예시 — NPC 설**

```
flag : eventSeol = true    // 설 이벤트 발생 여부
flag : saveSeol = true     // 설 구출 여부

[조우 이벤트 분기]

if !eventSeol :
    // 최초 조우: 어린 설 등장
    "동생이 산적에게 납치되었어요... 제발 도와주세요!"

else :
    if saveSeol :
        // 구출한 경우: 성인 설 등장, 우호적
        "과거에 모험가님과 닮은 분이 절 구해주셨어요.
         이번에는 그 분과 닮은 모험가님을 제가 도와드릴게요!"
    else :
        // 구출하지 못한 경우: 성인 설 등장, 적대적
        "산적에게 동생을 잃은 이후, 복수만을 위해 살아왔어.
         널 도우면 그 녀석들을 처단할 수 있는거지?!"
```

**적용 원칙**
- 플래그는 계정 단위로 저장되며 회차가 바뀌어도 유지된다.
- 유저는 플래그 시스템의 존재를 명시적으로 안내받지 않는다. 이전 선택의 영향을 '은연 중에 느끼는' 경험을 목표로 한다.
- 과도한 분기는 컨텐츠 제작 비용을 급증시키므로, 핵심 NPC에만 적용하고 나머지는 선택에 의한 호감도 수치로 단순화한다.

## 컨텐츠 예시 — 남서 지역 여정 구조

<!-- 이미지 영역 -->

**여정 해금 트리 (남서)**

```
[초행: 평원을 달려서] ──→ [상설: 상단 호위]
                                  │
[초행: 심마니] ──────────→ [상설: 사냥]
        │
        └─ (미스테리) ──→ [초행: 음유시인] ──→ [주의: 신기루 섬]
                                                       │
                                               (신기루) ↓
[초행: 평원을 달려서]                         [절세: 세이렌]
+ [상설: 상단 호위]                                    │
    (미스테리) ──→ [초행: 영약을 찾아서]              ↓
                        └──→ [주의: 산림욕]    [위험: 용왕의 섬]
                                (흔적) ──→ [절세: 고대 왕국]
                                                    ↓
                                            [위험: 유적 탐험]
```

| 여정 | 등급 | 해금 조건 |
|------|------|-----------|
| 평원을 달려서 | 초행 | 기본 해금 |
| 상단 호위 | 상설 | 평원을 달려서 완료 |
| 심마니 | 초행 | 기본 해금 |
| 사냥 | 상설 | 심마니 완료 |
| 도시를 향해 | 초행 | 상단 호위 또는 사냥 완료 |
| 영약을 찾아서 | 초행 | 평원을 달려서 + 상단 호위 (미스테리 이벤트) |
| 산림욕 | 주의 | 영약을 찾아서 완료 |
| 숨겨진 휴양지 | 초행 | 루얼스 해금 후 나수브 재방문 |
| 바닷바람 | 상설 | 숨겨진 휴양지 완료 |
| 실종자 수색 | 초행 | 숨겨진 휴양지 + 바닷바람 (미스테리 이벤트) |
| 바다낚시 | 주의 | 실종자 수색 완료 |
| 음유시인 | 초행 | 심마니 + 사냥 (미스테리 이벤트) |
| 신기루 섬 | 주의 | 음유시인 완료 |
| 세이렌 | 절세 | 음유시인 + 신기루 섬 (신기루 이벤트) 또는 실종자 수색 + 바다낚시 (미스테리 이벤트) |
| 용왕의 섬 | 위험 | 세이렌 완료 |
| 고대 왕국 | 절세 | 영약을 찾아서 + 산림욕 (흔적 이벤트) 또는 실종자 수색 + 바다낚시 (신기루 이벤트) |
| 유적 탐험 | 위험 | 고대 왕국 완료 |
