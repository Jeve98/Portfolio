### 헤더 영역

```
전연욱
Game Developer · Game Planner

Unity / C# · Phaser · Django · Vue.js
멀티플레이 네트워크 최적화 · 게임 시스템 기획 · 성능 튜닝

삼성 청년 SW 아카데미(SSAFY) 수료
```

> **개선 이유:** 기존 "모두에게 추억으로 남을 게임을 개발합니다"는 태도로서는 좋지만,  
> 채용 담당자가 첫 화면에서 가장 먼저 찾는 것은 "이 사람이 뭘 할 수 있는가"다.  
> 태그라인은 유지하되, 스킬 요약을 함께 배치해야 한다.

### 자기소개 영역

```
게임을 오래 즐긴 사람으로서, 플레이어가 무엇에 몰입하는지를 늘 생각합니다.
개발에서는 정돈된 구조와 수치로 증명하는 최적화를,
기획에서는 현재 시장 트렌드에 기반한 시스템 설계를 지향합니다.

SSAFY에서 멀티플레이 비대칭 PVP와 웹 기반 RPG를 팀 프로젝트로 완성했으며,
개인 기획 작업을 통해 장르 분석과 게임 시스템 설계 역량을 쌓고 있습니다.
```

> **개선 이유:** 기존 자기소개는 철학만 있고 경험 요약이 없었다.  
> 인사팀이 "어떤 사람인가"를 30초 안에 파악할 수 있도록 경험을 한 단락에 녹여야 한다.

### 네비게이션 구성 제안

기존: `홈 · 기획 · 프로젝트`

개선: `홈 · 개발 프로젝트 · 게임 기획`

> **개선 이유:** "프로젝트"라는 단어가 기획과 개발 모두를 포함하는 것처럼 읽혀서  
> 기획 섹션이 별도 존재한다는 것이 직관적으로 전달되지 않는다.  
> 개발과 기획을 명확히 분리된 탭으로 구성하면 직군별 지원 시 강조점을 맞출 수 있다.
