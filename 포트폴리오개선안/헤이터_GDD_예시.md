## 기획 배경

디펜스 장르는 타워 디펜스 시절부터 현재의 수집형 RPG와의 결합까지, 기본 시스템을 다르게 해석하고 다른 장르와 결합하며 높은 확장성을 보여온 스테디셀러 장르다.

그러나 장르 전반에 걸쳐 하나의 공통된 설계가 고수되고 있다. **현재 스테이지에서의 행동이 다음 스테이지에 영향을 주지 않는다**는 것이다. 한 스테이지에서 자원을 소모해 기물을 배치하더라도 그 소모량은 현재 스테이지 결과에만 영향을 미치고, 수집형 RPG 계열에서도 스테이지에서 쓰러진 캐릭터는 아무런 불이익 없이 다음 스테이지에 등장한다.

하지만 디펜스 장르의 본질은 **전쟁 중에 기지를 지키는 것**이다. 현실의 전쟁은 한 번의 전투가 이후 전투에 직접적인 영향을 미친다. 전투에서 입은 피해가 다음 전투의 출발점이 된다는 현실성은 그 자체로 몰입감을 만든다.

이 지점에서 질문이 생겼다. **만약 현재의 선택이 미래 전투에 영향을 미친다면, 플레이어는 어떻게 행동할까?** 지금 기물을 아끼면 이번 전투를 질 수 있고, 무분별하게 소모하면 이후 전투가 힘들어진다. 이 딜레마 자체가 디펜스 장르에서 볼 수 없었던 "사령관으로서의 경험"을 만든다.

여기에 **미래 정보의 비대칭**을 추가하면 판단의 무게가 더해진다. 다음 스테이지의 Wave 구성을 알 수 있다면 더 효율적인 판단이 가능하지만, 그 정보를 얻기 위해서는 사령관을 소모해야 한다. 정보를 사는 비용이 병력의 약화로 이어지는 구조다.

## 기획 의도

배경 분석을 바탕으로 다음 설계 결정을 내렸다.

| 결정 | 근거 | 구현 방향 |
|------|------|-----------|
| 병력 영구 손실 | 스테이지 간 지속성이 핵심 경험 | 전투 사망 병력은 가용 인원에서 영구 제거 |
| 탐사 vs 사령관 모집 선택 | 정보 비대칭으로 판단 무게 강화 | 스테이지 성공 후 둘 중 하나만 선택 가능 |
| 랜덤 Wave 구성 | 동일 전략 반복 방지, 다회차 유도 | 난이도별 Wave를 랜덤하게 조합 |
| 탐사의 정신력 소모 구조 | 정보 획득 비용을 병력 약화로 설정 | 탐사 진행 시 사령관 정신력 소모, 절반 미만 시 다음 스테이지 불가 |
| 골드 기반 추가 배치 | 전쟁 중 판단 선택지 제공 | 전쟁 단계에서 골드 소모로 추가 병력 배치 가능, 해당 병력은 게임 종료 후 편입 |

## 게임 필라 (Game Pillars)

| 필라 | 설명 | 구현 방법 |
|------|------|-----------|
| 지속성 전쟁 | 현재의 손실이 미래를 결정한다 | 병력 영구 손실, 스테이지 간 자원 이어짐 |
| 전략적 딜레마 | 아끼면 지고, 쓰면 나중을 망친다 | 골드 소모 추가 배치, 탐사 비용 구조 |
| 정보 비대칭 | 미래를 알면 유리하지만 공짜는 없다 | 탐사로 Wave 정보 획득, 사령관 정신력 소모 |
| 반복 가능성 | 매 회차 다른 전장 | 난이도별 랜덤 Wave 조합 |

## 코어 루프 (Core Loop)

```
[스테이지 선택]
    연대기 지도에서 도전할 스테이지 선택
        ↓
[배치 단계]
    사령관 선택 → 병력 배치 → 사령관 위치 결정
    (Wave 정보는 이 시점에 비공개)
        ↓
[전쟁 단계]
    시뮬레이션 전투 진행
    필요 시 골드 소모로 추가 병력 배치 가능
        ↓
[스테이지 결과]
    ├─ 성공: 골드 획득 → [사령관 모집 / 탐사] 선택 → 병력 모집
    └─ 실패:
        ├─ 모든 병력 전멸 + 골드 부족 → 재도전 또는 항복
        └─ 성벽 체력 0 → 재도전 또는 항복
        ↓
[자동 저장 → 지도 복귀]
```

**탐사 루프**

```
[탐사 진입]
    사령관 선택 (소모 자원)
        ↓
[5개 스테이지 순차 진행]
    매 스테이지: 사령관 정신력 랜덤 감소
    스테이지 클리어 시: 다음 스테이지 Wave 정보 획득
    판단: 계속 진행 / 탐사 종료
        ↓
[결과]
    최종 스테이지 도달 + 정신력 잔존 → 강력한 사령관 획득
    정신력 절반 미만 → 다음 방어전 참여 불가
    정신력 0 → 자동 종료
```

## 컨텐츠 구조

### 디펜스

| 단계 | 설명 | 제약 |
|------|------|------|
| 배치 단계 | Cell에 병력 배치, 사령관 위치 결정 | Wave 정보 비공개. 배치·취소 가능 |
| 전쟁 단계 | 배치된 병력과 적 유닛의 시뮬레이션 전투 | 재배치 불가. 골드 소모로 추가 배치는 가능 |

**스테이지 클리어 실패 조건**
- 성벽 체력이 0이 된 경우
- 배치 병력 전멸 + 추가 배치 가능한 골드 없음

### 탐사

| 항목 | 내용 |
|------|------|
| 진입 비용 | 사령관 선택 (소모) |
| 스테이지 수 | 5개 |
| 매 스테이지 효과 | 사령관 정신력 랜덤 감소 |
| 보상 | 스테이지마다 다음 Wave 정보 획득 |
| 최종 보상 | 마지막 스테이지 도달 + 정신력 잔존 시 강력한 사령관 획득 |
| 제약 | 정신력 50% 미만 사령관 → 다음 방어전 불참. 모든 사령관 정신력 0 → 자동 종료 |
| 선택지 | 매 스테이지마다 진입 / 종료 선택 가능 |

## 시스템 명세

### 사령관 시스템

디펜스에서는 특정 Cell에 배치되어 인근 병력에게 패시브 버프를 제공한다.  
탐사에서는 소모 자원으로 사용된다.

**패시브 버프 종류 (예시)**

| 종류 | 효과 |
|------|------|
| 물리 데미지 향상 | 인근 병력의 물리 공격력 증가 |
| 마법 데미지 향상 | 인근 병력의 마법 공격력 증가 |
| 고정 마법 데미지 추가 | 모든 공격에 고정 마법 데미지 추가 |
| 방어력 향상 | 인근 병력의 방어력 증가 |
| 회복량 향상 | 인근 병력의 회복 효과 증가 |

### 병력 시스템

5개 병과로 구성된다. 병력 수는 HP와 동일하게 취급되어 전투 피해에 따라 감소한다.  
일정 횟수의 전투를 경험하면 등급이 상향되며, 하위 부대 편입으로 인원을 보충할 수 있다.

| 병과 | 특성 |
|------|------|
| 보병 | 평균적인 방어력과 물리 공격력 |
| 마법병 | 낮은 방어력, 높은 마법 공격력 |
| 포병 | 높은 방어력과 물리 공격력. 범위 공격 가능, 공격 속도 느림 |
| 방패병 | 높은 방어력, 낮은 물리 공격력 |
| 신관 | 낮은 방어력. 주위 병력 회복 |

### 적 유닛 특성 시스템

단일 병과만으로 모든 적을 처리하는 전략을 방지하기 위해 다양한 특성을 부여한다.

| 특성 | 효과 |
|------|------|
| 물리 면역 | 물리 공격 피해 무효 |
| 마법 면역 | 마법 공격 피해 무효 |
| 범위 면역 | 범위 공격 피해 무효 |
| 회복 불가 | 아군 유닛의 회복 효과 차단 |
| 데미지 반사 | 입은 피해만큼 공격자에게 반사. 대신 체력이 매우 낮음 |
| 원거리 공격 | 근접 배치 병력을 넘어 후열 공격 가능 |
| 돌파 | 병력 유닛을 무시하고 성벽 직접 공격 |
| 그로기 | 매우 높은 체력. 누적 피해 일정량 초과 시 그로기 상태 진입 |

## 개발 반영 시 변경 사항

> 본 기획을 기반으로 SSAFY 팀 프로젝트로 실제 개발이 진행되었다.  
> 한 달의 개발 기간과 가용 에셋 제약으로 인해 아래와 같이 수정되었으며,  
> 각 변경 사항은 팀원이 문서화하고 팀 승인을 거쳐 반영되었다.

| 초기 기획 | 수정 기획 | 변경 이유 |
|-----------|-----------|-----------|
| 탐사 단일 컨텐츠 | 정찰(Low Risk-Low Return) / 탐사(High Risk-High Return) 이원화 | 기존 탐사는 정찰로 편입, 탐사는 세계관 몰입 강화 컨텐츠로 확장 |
| 사령관 — Cell 소모, 인근 유닛 버프 | 사령관 — 전체 유닛 버프로 변경 | Cell을 소모하는 배치 방식이 세계관(사령관이 공격받지 않음)과 불일치 |
| 아군 유닛 기본 구성 | 토템 유닛 추가 | 게임 초반 사령관 획득 전 Cell 소모 버프 역할 보완 |
| 적 유닛 개별 특성 | 스탯 차별화로 대체 | 가용 에셋 한계 및 일정 제약으로 특성 구현 대신 스탯으로 개성 부여 |
| — | 영지 컨텐츠 추가 | 다회차 빌드 체험 부족 → 시설물 업그레이드로 추가 재화 및 특수 효과 제공 |
| 재화: 골드 단일 | 재화: 골드 + 식량 이원화 | 골드만으로는 전술적 제약이 부족 → 식량으로 보유 유닛 수 강제 제한 |
