# 헤이터 (Hater) — 게임 기획 컨셉 문서

> 개선 포인트: 2일짜리 기획이라 무게감이 부족 / 기획서 형식 미비 / 시각 자료 부족  
> 개선 방향: "짧은 기간의 아이디어 기획"이라는 것을 명시하고, GDD 형식으로 구조를 갖춰  
> "기획 사고력을 보여주는 컨셉 문서"로 포지셔닝한다.

---

## 문서 성격 안내

이 문서는 **2일간 진행한 집중 기획 작업의 결과물**이다.  
완성된 게임이 아닌 게임 시스템 설계 컨셉 문서이며, 기획자로서의 사고 과정을 보여주는 것이 목적이다.

---

## 1. 게임 개요 (엘리베이터 피치)

> **"매 스테이지의 병력 손실이 다음 스테이지에 그대로 이어지는 디펜스 게임.  
> 현재의 선택이 미래를 바꾸기 때문에, 플레이어는 항상 두 스테이지를 동시에 생각해야 한다."**

| 항목 | 내용 |
|------|------|
| 장르 | 전략 디펜스 |
| 플랫폼 | PC (가정) |
| 플레이 인원 | 1인 |
| 예상 플레이 시간 | 회차당 2~4시간 |
| 핵심 키워드 | 영구 손실, 인과 전략, 리플레이어빌리티 |

---

## 2. 기획 배경 — 기존 장르의 문제점

기존 디펜스 게임은 각 스테이지가 독립적이다. 현재 스테이지에서의 전략이 다음 스테이지에 영향을 미치지 않기 때문에 플레이어는 "지금 이기는 것"만 생각하면 된다.

이 게임은 현실의 전쟁처럼 **병력 손실이 누적**되도록 설계함으로써, 플레이어가 미래를 고려하며 현재를 플레이하도록 유도한다. 지금 전력을 쏟으면 다음 스테이지가 어려워지고, 아끼면 클리어가 힘들어지는 선택의 긴장감을 만든다.

## 3. 타겟 플레이어

| 항목 | 내용 |
|------|------|
| 주 타겟 | 전략 게임에 익숙한 20~30대 |
| 참조 게임 | 배틀 브라더스, FTL, 디펜스 오브 더 앵션트 |
| 핵심 니즈 | "매 판마다 다른 경험", "전략적 선택의 결과를 느끼고 싶다" |
| 기피 유형 | 단순 반복 클리어를 원하는 캐주얼 유저 |

---

## 4. 핵심 게임플레이 루프

```
[지도에서 스테이지 선택]
        ↓
[배치 단계] — 병력·사령관을 셀에 배치 (웨이브 정보 미공개)
        ↓
[전쟁 단계] — 시뮬레이션 자동 전투 (배치 변경 불가)
        ↓
[결과 처리] — 병력 손실 영구 적용 / 골드 획득
        ↓
[선택 분기] ─── 사령관 모집 (안정)
             └── 탐사 진입 (고위험 고수익)
        ↓
[자동 저장 후 지도로 복귀]
        ↓
[전멸 또는 항복 → 초기화]
```

## 5. 주요 시스템 설계

### 5-1. 유닛 시스템

**아군 — 병과 5종**

| 병과 | 특성 |
|------|------|
| 보병 | 균형잡힌 스탯 |
| 마법병 | 낮은 방어 + 높은 마법 공격 |
| 포병 | 높은 방어 + 범위 공격 (낮은 공속) |
| 방패병 | 높은 방어 + 낮은 공격 |
| 신관 | 낮은 방어 + 아군 회복 |

**아군 — 사령관**
- 5가지 이상 패시브 버프 제공 (물리/마법 데미지 향상, 방어력 향상, 회복량 향상 등)
- 배치된 셀의 부대에 버프 적용

**병력 운용 원칙**
- 하나의 부대 = 하나의 유닛 (체력 감소 = 인원 감소)
- 전투 경험으로 등급 상향 가능
- 편입 시 일부 손실 발생 (합류 비용)

---

**적군 — 면역/특수 능력으로 단일 전략 방지**

특정 병과만 사용하는 전략을 차단하기 위해 적마다 다양한 면역 능력을 부여했다.

| 능력 | 효과 |
|------|------|
| 물리 면역 | 물리 공격 무효 |
| 마법 면역 | 마법 공격 무효 |
| 범위 면역 | 범위 공격 무효 |
| 회복 무효 | 아군 회복 효과 무효화 |
| 데미지 반사 | 받은 데미지 일부 반사 |
| 원거리 공격 | 근접 셀 무시하고 후방 공격 |
| 관통 공격 | 벽 무시 |
| 그로기 부여 | 피격 시 일시 행동 불가 |

---

### 5-2. 탐사 컨텐츠

스테이지 클리어 후 진입 가능한 선택적 고위험 고수익 콘텐츠.

- 제한된 수의 사령관으로 5개 소규모 스테이지 연속 진행
- 각 진입 시 사령관 정신력 랜덤 감소 (능력치 페널티)
- 다음 스테이지 적 정보 사전 제공 (정보 이점)
- 최종 스테이지 클리어 시 강력한 사령관 획득

## 6. 리플레이어빌리티 설계 근거

| 요소 | 방법 |
|------|------|

| 랜덤 웨이브 구성 | 동일한 전략으로 연속 클리어 불가 |

| 사령관 조합 | 어떤 사령관을 얻느냐에 따라 전략 변화 |
