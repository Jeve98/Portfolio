### 1. Min-Heap 기반 보스 패턴 시스템

**문제:** 보스 패턴을 랜덤 함수로 선택하면 편차가 크고, 쿨타임 기반 방식은 강한 패턴이 특정 구간에 집중된다.

### 2. 안전 구역 기반 스폰 시스템

**문제:** 몬스터 스폰 시 지형지물과 겹치는 현상 발생. 매 프레임 충돌 연산으로 해결하려 하면 성능 비용이 크다.

**해결:** 미리 설정해둔 안전 좌표 리스트에서 스폰 위치를 선택하는 방식을 채택했다.  
다중 안전 좌표와 반발 로직으로 몬스터 중복 배치를 최소화하면서, 불필요한 프레임별 충돌 연산을 제거했다.

---

### 3. 컷씬 중복 재생 방지 — 비트 연산 활용

플레이어의 컷씬 시청 기록을 DB에 저장할 때, 컷씬 수만큼 컬럼을 늘리는 대신 **비트 플래그**로 압축 저장했다.

```python
# 예시: 컷씬 4개를 정수 1개로 관리
watched_flags = 0b0101  # 1번, 3번 시청 완료

def has_watched(flags, cutscene_id):
    return bool(flags & (1 << cutscene_id))

def mark_watched(flags, cutscene_id):
    return flags | (1 << cutscene_id)
```

**효과:** DB 컬럼 수 고정, 조회 연산 O(1), 컷씬 추가 시 DB 스키마 변경 불필요.

### 4. Phaser Scene 로딩 최적화

전체 Scene을 한 번에 로드하는 구조로 인해 유령 오브젝트와 import 중복이 발생했다.  
Scene 단위 지연 로딩으로 전환하여 초기 로딩 시간을 단축하고 메모리 점유를 줄였다.

---

### 5. Django REST API 서버 구축

SQLite3 기반 서버를 구축했다. SQLite3는 write-lock 제약이 있어 동시 쓰기에 취약하지만,  
이 게임은 1인용이고 조회 중심 구조로 설계되어 있어 실제 운영 환경에서 충분히 대응 가능하다고 판단했다.

---

### 6. AI 생성 코드 구조화 경험

팀원이 AI 코딩 도구로 생성한 대량의 비정형 코드를 분석하고 재정비했다.

**사례 1 — 스킬 시스템:**  
기존 코드의 흐름도를 직접 작성하고, 이상적인 구조를 문서화하여 리팩토링 방향을 제시했다.

**사례 2 — 데이터 동기화 누락:**  
API 데이터가 특정 조건에서 동기화되지 않는 버그를 역행 분석(데이터 흐름 역추적)으로 발견하고 수정했다.

> 이 경험은 AI 생성 코드를 맹신하지 않고 구조와 흐름을 직접 파악하는 능력이 있음을 보여준다.
