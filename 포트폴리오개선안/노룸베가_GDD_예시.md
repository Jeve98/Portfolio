## 기획 배경

RPG의 핵심 재미 요소를 다음 5가지로 정의하고, 각 요소의 현재 트렌드를 분석하였다.

| # | 요소 | 관찰 |
|---|------|------|
| 1 | 성장 체감 | 중요도 유지 |
| 2 | 제 2의 정체성 (MMO 사회성) | 코로나 이후 개인화된 생활 패턴이 현실의 사회관계에 대한 피로를 높이면서 약화. 일본의 '인간관계 리셋' 문화 유행이 이를 반증 |
| 3 | 보스레이드 몰입·카타르시스 | 중요도 유지 |
| 4 | 스토리 | 세계관을 파헤치는 탐구형과 스킵형으로 양극화. 스토리 감상에는 장기간의 체험이 필요한데, OTT·Shorts·릴스 등 즉발 체험 컨텐츠의 확산으로 이 비용을 감수하는 유저가 줄어들고 있다. ROI 관점에서 매력 하락 |
| 5 | 득템 도파민 | 중요도 유지 |

여기서 특히 주목한 것은 **2번의 약화**와 **4번의 ROI 문제**다. 사회성 기반 리텐션이 약해졌다면, 초기에 유저를 붙잡아야 하는 요소는 더욱 즉각적이고 개인적인 체험이 되어야 한다.

이를 확인해준 사례가 2025년 1분기 던전 앤 파이터의 '던닝(종말의 숭배자 던전)' 이벤트다. 1·5번 요소에만 집중한 성장 이벤트였음에도 대규모 유저 유입을 이끌어냈다. 이는 게임 초반의 체험 집중도가 장기 리텐션 설계보다 단기 유입에 더 직접적으로 작용함을 보여준다.

결국 이 게임에서 풀어야 할 핵심 질문은 하나였다. **"2번과 4번을 배제하고도 유저를 붙잡는 구조를 만들 수 있는가?"**

## 기획 의도

배경 분석의 결론으로 **2번을 배제하고 1·3·5번을 보스레이드 단일 컨텐츠 아래 통합**하는 방향을 결정하였다.

| 결정 | 근거 | 구현 방향 |
|------|------|-----------|
| 1·3·5번 요소 통합 | 약화된 2번·ROI 낮은 4번 배제 | 보스레이드를 중심 축으로 세 요소 동시 달성 |
| 보스레이드로 성장 체감(1) 제공 | 클리어 보상이 즉각적 성장으로 연결되어야 함 | 보스 클리어 시 확정 아이템 드랍, 등급별 수치 차이 극대화 |
| 기믹 보스로 카타르시스(3) 설계 | 단순 DPS 경쟁은 카타르시스 없음 | 반전·선고·탐욕·저주 기믹으로 이해 → 클리어 구조 |
| 랜덤 드랍 + 등급으로 득템(5) 유지 | 지속적 파밍 동기 필요 | 랜덤 스킬·스탯·속성, 결정·토큰으로 재도전 유도 |
| 스토리(4) 최소화 | ROI 매력 하락, 개발 비용 대비 효과 낮음 | 마왕 사념 부활이라는 최소 세계관 틀만 설정 |

## 게임 필라 (Game Pillars)

| 필라 | 설명 | 구현 방법 |
|------|------|-----------|
| 즉각적 성장 체감 | 초기부터 강렬한 성장 곡선 제공 | 보스 클리어 시 확정 아이템 드랍, 등급별 수치 차이 극대화 |
| 보스레이드 카타르시스 | 기믹 이해 → 클리어의 성취감 | 반전·선고·탐욕·저주 기믹 보스 설계 |
| 빌드 다양성 | 나만의 전략 조합 체험 | 무기 스킬 + 방어구 패시브 + 장신구 속성 시너지 |
| 득템 도파민 | 드랍에 의한 지속적 동기 부여 | 랜덤 스킬·스탯·속성 + 등급 5종 + 결정/토큰으로 재도전 |

## 코어 루프 (Core Loop)

```
[던닝] (일일 5회)
    방어구 / 장신구 드랍 → 패시브 스탯·속성 옵션 확인
        ↓ (보완)
[보스레이드]
    보스 선택 → 패턴·기믹 파악 → 클리어
        ↓
    무기(랜덤 액티브 스킬) + 결정 드랍
        ↓
[빌드 강화]
    결정으로 무기 스킬 재롤 / 토큰으로 무기 수치 재롤
        ↓
[상위 난이도 도전]
    더 높은 난이도의 보스 → 더 높은 등급 아이템
        ↓ (반복)
```

## 컨텐츠 구조

### 보스 레이드

n종의 보스를 각각 세분화된 난이도로 제공한다.

| 요소 | 내용 |
|------|------|
| 보스 수 | n종 (시즌마다 추가) |
| 난이도 | 보스별 다단계 난이도 |
| 드랍 | 무기 (랜덤 액티브 스킬), 결정 |
| 특이사항 | 최고 난이도 보스에서 낮은 확률로 도감 아이템 추가 드랍 |

### 던닝 (일일 컨텐츠)

| 요소 | 내용 |
|------|------|
| 일일 횟수 | 5회 |
| 등급 상승 확률 | 현재 토벌된 보스 난이도에 비례하여 증가 |
| 드랍 | 방어구 (랜덤 패시브 스탯), 장신구 (랜덤 속성 옵션), 토큰 |

## 아이템 시스템

### 아이템 등급

| 등급 | 무기 스킬 수 | 무기 수치 범위 | 방어구 수치 범위 | 장신구 가용 속성 |
|------|------------|--------------|----------------|----------------|
| 노멀 | 1개 | 1~5 | 1~5 | 없음 |
| 수작 | 1개 | 8~21 | 8~21 | 화염, 물 |
| 명품 | 2개 | 34~55 | 21~55 | 화염, 물, 바람 |
| 유일 | 3개 | 89~144 | 55~89 | 전 속성 |
| 악몽 | 3개 | 55~144 | 55~144 | 전 속성 + 열화 속성 1개 추가 |

※ 악몽 등급 무기는 방어구 계열 패시브 스탯 중 1개를 -21~8 수치로 추가 보유  
※ 악몽 등급 장신구에서 동일 속성이 중복될 경우, 방어구 스탯 1개를 1~8 수치로 대체

### 무기 시스템

- 보스 클리어 시 랜덤 액티브 스킬이 부여된 무기 드랍
- **결정** 소모 → 무기의 액티브 스킬 랜덤 변경 (등급별 변경 가능 횟수 상한)
- **토큰** 소모 → 무기의 공격력/마력 수치 랜덤 변경

### 방어구 시스템

- 던닝 클리어 시 랜덤 패시브 스탯이 부여된 방어구 드랍

**패시브 스탯 종류**

| 스탯 | 효과 |
|------|------|
| 공격속도 | 공격 속도 증가 |
| 방어력 | 피해 감소 |
| 속성 반감 | 보스 속성 공격 피해 감소 |
| 마나 소모량 | 스킬 마나 소모 감소 |
| 마나 회복량 | 마나 자연 회복 증가 |
| 스킬 쿨타임 | 스킬 재사용 대기 시간 감소 |

### 장신구 시스템

- 던닝 클리어 시 랜덤 속성 옵션이 부여된 장신구 드랍
- 최대 2개 동시 착용, 속성 효과 중첩 적용

**속성 옵션 종류**

| 속성 | 효과 |
|------|------|
| 화염 | 공격 시 도트 데미지 추가 |
| 물 | 공격 시 대상 이동속도 하락 디버프 |
| 바람 | 일정 확률로 모든 스킬이 타겟팅화 |
| 어둠 | 모든 공격이 범위형으로 변경 |
| 빛 | 공격 시 대상 명중률 하락 디버프 |

## 보스 패턴 / 기믹 명세

### 기믹 구조 원칙

- 각 보스는 1개 이상의 기믹을 보유한다.
- 기믹은 단순 DPS 경쟁이 아닌 **패턴 이해와 판단**을 요구하도록 설계한다.
- 난이도별로 기믹 오브젝트가 추가 개방된다.

### 기믹 1 — 반전

파괴 가능한 반전 오브젝트가 발동하면 해당 효과가 적용된다.  
파괴된 오브젝트의 패턴은 현재 전투에서 재등장하지 않는다.  
단, 반전 적용 중 오브젝트 파괴 시 전투 종료까지 효과 유지.

| 반전 종류 | 효과 | 지속 시간 | 비고 |
|-----------|------|-----------|------|
| 반전[스탯] | 패시브 스탯을 `최대치(100) - 현재 스탯`으로 반전 | 60s ~ 100s | — |
| 반전[조작] | 조작 키 입력 반전 | 10s ~ 30s | — |
| 반전[데미지] | 데미지와 회복 효과 반전 | 5s ~ 20s | — |
| 반전[속성] | 보스 내성 속성 랜덤 변경 | 지속 | — |
| 반전[시점] | 보스 시점으로 전환 (멀티: 플레이어 시점 교환) | 60s (멀티 20s) | 3D 프로젝트 한정, 기술 검토 필요 |

※ 오브젝트가 빛날 때 반전 효과 활성화

### 기믹 2 — 선고

보스가 사망지대를 생성한다.

1. 유저 또는 몬스터가 사망지대에서 일정 시간 이상 머무르면 **죽음이 선고**된다.
2. 선고 받은 몬스터는 보스를 적으로 인식하고 공격한다. 유저에게는 공격하지 않는다.
3. 일정 시간 후 보스가 동/서/남/북 중 한 방향으로 **확정기**를 발사한다.
4. 해당 방향의 선고 받은 모든 개체는 즉사한다.

**전략 포인트**: 몬스터를 선고 구역에 유도하여 보스 공격에 활용하되, 확정기 방향을 예측하고 피해야 한다.

### 기믹 3 — 탐욕

보스가 다양한 속성 내성을 지닌 체력 1의 몬스터를 소환한다.

- 일정 시간 후 몬스터는 자동 디스폰된다.
- **사망한 몬스터의 수에 비례하여 보스 체력이 회복**된다.

**전략 포인트**: 다양한 속성 공격으로 최대한 많은 몬스터를 처치해야 한다. 속성 반감 장신구 선택이 보스 공략에 직접 영향을 미친다.

### 기믹 4 — 저주

보스의 특정 패턴에 피격되면 **저주 표식**이 일정 시간 새겨진다.

저주 표식 적용 상태에서:
- 보스에게 데미지를 가할 경우 → 가한 데미지에 비례하여 자신의 체력 감소
- 회복 시 → 회복량에 비례하여 보스 체력 증가

**전략 포인트**: 저주 지속 시간 동안 공격을 자제하거나, 저주 해제 수단을 확보해야 한다.

## 장기 리텐션 전략

단기 성장 체감과 보스 카타르시스만으로는 장기 리텐션에 한계가 있다. 다음 네 가지 전략으로 보완한다.

### 1. 빌드형 체험 강화

장신구 속성 간 **시너지 효과**를 추가하여 단순 속성 선택을 넘어 빌드 설계 체험으로 확장한다.

예시:
- 화염 + 물 조합 → 피해 감소 디버프 상태에서 도트 데미지 2배
- 바람 + 어둠 조합 → 랜덤 타겟팅 범위 공격 시 추가 효과

### 2. 시즌제

| 항목 | 내용 |
|------|------|
| 시즌별 변화 | 신규 무기 스킬, 장신구 속성, 시즌 보스 추가 |
| 목적 | 동일 플레이 사이클 내 새로운 체험 제공 |

### 3. 보스 패턴 다변화

동일 보스라도 난이도별 신규 패턴을 추가한다.  
상위 난이도는 하위 난이도와 다른 보스를 상대하는 느낌을 제공하여 도전 동기를 지속시킨다.

### 4. 도감 컨텐츠

각 시즌 최고 난이도 보스에서 낮은 확률로 추가 드랍되는 **도감 아이템**을 추가한다.

- 도감 아이템은 세계관 서사를 강화하는 역할을 한다.
- '도감을 완성한다'는 장기 목표를 제공하여 최상위 컨텐츠 소진 후에도 플레이 동기를 유지시킨다.

### 리텐션 단계별 설계 요약

| 단계 | 목표 | 수단 |
|------|------|------|
| 초반 (신규 유입) | 즉각적 성장 체감으로 이탈 방지 | 던닝 성장 이벤트, 낮은 진입 난이도 |
| 중반 (코어 유저) | 빌드 체험으로 플레이 다양성 확보 | 속성 시너지, 결정/토큰 재롤 시스템 |
| 장기 (하드코어) | 도전과 수집으로 장기 목표 제공 | 최고 난이도 보스, 도감 컨텐츠, 시즌제 |
